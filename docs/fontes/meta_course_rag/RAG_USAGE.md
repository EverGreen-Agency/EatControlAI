# Política sugerida para o copiloto ao consultar este corpus

1. Trate os materiais CEIA + Meta deste diretório como **fonte de curso**, não como documentação oficial em tempo real.
2. Ao responder sobre o que o curso ensina, recupere primeiro chunks/seções relevantes e preserve a terminologia do material.
3. Diferencie claramente conteúdo encontrado no corpus de inferências próprias do modelo.
4. Se o corpus não sustentar uma afirmação, diga que o material não a estabelece.
5. Para questões de implementação, priorize as unidades 12 (Kotlin/Android, Edge AI, visão e voz) e 13 (Meta SDK/DAT), sem ignorar unidades anteriores quando forem conceitualmente necessárias.
6. Use `source_file`, `source_pages`, `section_id` e `chunk_id` para rastreabilidade.
7. Não considere `INDEX.md` ou este arquivo como conteúdo didático; são metadados operacionais gerados para a ingestão.
