# PRD — Product Requirements Document

## 1. Objetivo do produto
Entregar orientação alimentar educativa e contextual no instante da escolha, usando AI glasses como
interface hands-free.

## 2. Personas
### P1 — Paciente / usuário GLP-1
Quer decidir rapidamente o que comer, acompanhar padrões e reduzir fricção.

### P2 — Profissional de saúde
Configura/revisa metas, restrições, orientações e acompanha relatórios autorizados.

### P3 — Operador/Admin
Administra regras, fontes, versões de modelos, telemetria e conteúdo.

## 3. Jobs-to-be-done
- "Quando estou diante de um prato/rótulo, quero saber se ele está alinhado ao meu plano."
- "Quando a informação é incerta, quero saber que é incerta."
- "Quero registrar decisões sem preencher formulários."
- "Como profissional, quero acompanhar o que o paciente registrou sem transformar o sistema em prescriptor."

## 4. MVP
- Conectar óculos ao app.
- Capturar imagem.
- Capturar comando de voz.
- OCR de rótulo.
- Scan de código de barras.
- Perfil local fictício/configurável.
- Motor determinístico: compatível / incompatível / informação insuficiente.
- TTS via óculos.
- Logs de latência e resultado.
- Uma análise visual de prato com incerteza explícita.

## 5. Fora do MVP
- Prescrição clínica.
- Ajuste de dose.
- Diagnóstico.
- Estimativa clínica precisa de calorias/macros por foto.
- Dashboard médico completo.
- Multi-tenant B2B.
