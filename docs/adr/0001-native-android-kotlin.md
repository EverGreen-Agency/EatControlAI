# ADR-0001 — Native Android / Kotlin no hackathon
Status: Accepted

## Contexto
O núcleo DAT, streaming, áudio e IA on-device é sensível a latência e lifecycle.

## Decisão
Construir o app do hackathon em Kotlin/Android nativo.

## Consequências
+ acesso direto ao SDK
+ menos bridge
+ melhor alinhamento ao material do programa
- não teremos iOS no MVP
