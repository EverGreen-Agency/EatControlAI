# User Flows

## UF-01 — Rótulo
Usuário olha → pergunta → captura → OCR → parser → regras → resposta por áudio → registro.

## UF-02 — Produto com barcode
Usuário olha → scan → produto → base → perfil → regras → resposta → registro.

## UF-03 — Prato
Usuário olha → captura sob demanda → modelo visual → evidências → pergunta de confirmação se necessário
→ regras → resposta com nível de confiança.

## UF-04 — Configuração no app
Usuário/profissional configura restrições, metas e orientações → persistência local → versão de perfil.

## UF-05 — Incerteza
Sistema não encontra evidência suficiente → informa explicitamente → recomenda confirmar ingrediente/preparo.
